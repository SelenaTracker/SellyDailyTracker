Sobre o Projeto

Este é um site fanmade, criado para acompanhar manualmente os streams e metas das músicas de Selena Gomez no Spotify. Meu principal objetivo, é fazer com que nós Selenators possamos nos organizar melhor, e focar nas músicas da Selena que estão prestes a atingir novas metas.

Nem todos os dados públicos que o Spotify divulga estão em fácil acesso para todos, isso porque só é permitido acessar os streams totais de 10 músicas pelo celular. Para acessar os streams totais de todo o catálogo, só é possível pelo computador. Como um fã que quer ajudar nas metas irá se informar se não tem um computador?

Nós servimos como esse guia para que os dados estejam disponíveis a todos em qualquer dispositivo.

Termos de Uso

Ao acessar e utilizar o site Selena Gomez Tracker, você concorda com os seguintes termos:

1. Uso Informativo

Este site é uma ferramenta fanmade (feita por fãs) e tem caráter meramente informativo. Os dados de streams são coletados para ajudar na organização de metas da comunidade.

2. Precisão dos Dados

Embora façamos o melhor para manter os números atualizados, os dados podem apresentar pequenas variações em relação aos números oficiais em tempo real do Spotify.

3. Vínculos

Não possuímos qualquer vínculo oficial com a artista Selena Gomez, sua gravadora ou com o Spotify. Este é um projeto independente de fã para fã.

Política de Privacidade

Sua privacidade é importante para nós.

1. Dados Coletados

Este site não coleta informações pessoais identificáveis dos visitantes. Os dados inseridos na calculadora são processados apenas no seu navegador.

2. Cookies e Anúncios

Utilizamos tecnologias como cookies para melhorar sua experiência e permitir que parceiros (como o Google AdSense) exibam anúncios relevantes para manter o site ativo.
